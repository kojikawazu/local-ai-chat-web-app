# プロンプトテンプレート 設計書

> 最終更新: 2026-11-01

よく使うプロンプトをテンプレートとして保存し、入力欄で `/` を打つと候補を出して、選んだテンプレートの本文を入力欄に入れるための設計（#28 の Phase A・B。サブ issue #206）。テンプレートの変数（`{{input}}`）・カテゴリ・インポート / エクスポート（#28 Phase C）は含めない。

## 背景

「以下を英語に翻訳してください:」「以下のコードをレビューしてください:」のような決まった前置きを、毎回打つか、どこかからコピーしている。入力欄で `/translate` と打って選ぶだけで入れられるようにする。

## 会話の役割との違い

近い機能に会話の役割（システムプロンプト。#10・`lib/chat/system-prompt.ts`）がある。混ぜないために役割を分ける。

| | 会話の役割 | プロンプトテンプレート |
|---|---|---|
| 効く範囲 | その会話のすべての送信（system メッセージ） | 1 回の入力（user メッセージの本文） |
| 入れ方 | ヘッダーのボタンからダイアログで選ぶ | 入力欄で `/` を打って選ぶ |
| 保存 | 会話の `systemPrompt` | テンプレートの一覧（会話に依らない） |
| 送る前の編集 | ダイアログで書き換えて保存 | 入力欄に入った本文をそのまま書き換えて送る |

テンプレートは入力欄に文字を入れるだけで、送信・API・会話の保存には何も足さない。

## 範囲

| 含める | 含めない（[やらないこと](#やらないこと)） |
|---|---|
| テンプレートの保存（DB）と CRUD の API | テンプレートの変数（`{{input}}`）（#28 Phase C） |
| 入力欄の先頭の `/` で候補を出し、選ぶと本文を入れる | カテゴリ・管理画面の検索（#28 Phase C） |
| 管理画面（一覧・作成・編集・削除） | JSON のインポート / エクスポート（#28 Phase C） |
| 空の一覧に例の 4 件を足すボタン | 送信時の展開（`/translate こんにちは` を送ると展開する） |

## 決めること（レビューの論点）

| 論点 | 推奨 | 他の案 | 理由 |
|---|---|---|---|
| 範囲 | **Phase A・B まで**（保存・CRUD・`/` の呼び出し・管理画面と、そのテスト）。Phase C は別の issue | 変数まで一度に入れる | 使ってみてから、変数・カテゴリが要るかを決める。変数は本文の書式を決める必要があり、後から足しても今の本文はそのまま使える |
| 保存先 | **DB の `PromptTemplate` テーブル**（マイグレーションあり） | localStorage | 会話と同じく PostgreSQL に置けば、ブラウザを変えても残る。localStorage は消えやすく、IT で検証できない |
| 既定のテンプレート | **持たない**。一覧が空のとき、管理画面と候補に「例を追加」を出し、押すと例の 4 件（翻訳・レビュー・要約・スライド。スライドは #36 で足した）を作る | シード（`prisma db seed`）・マイグレーションで INSERT・コードの定数（組み込みで編集できない） | シードは手で流さないと入らず、既存の DB には届かない。マイグレーションの手での編集はルールで禁じている。組み込みにすると「直したいのに直せない」ものができる。例を作るだけなら、作った後は利用者のものとして自由に直せる |
| カテゴリ | **今は持たない**（列も作らない） | issue の案のとおり `category` の列を先に作る | 使わない列を先に置くと、空の値の扱いだけが増える。Phase C で足すときにマイグレーションを足す |
| 候補を出す条件 | **入力欄の先頭が `/` で、空白・改行が出るまで**（`/` だけでも全件を出す） | どの位置の `/` でも出す・行頭なら出す | 文の途中の `/`（URL・パス・`A/B`）で出ると邪魔になる。入力欄の先頭に限れば、まだ何も書いていないときだけに絞れる |
| 候補の絞り込み | **ショートカットの前方一致**、続けて**名前の部分一致**（大文字・小文字を区別しない） | ショートカットの前方一致だけ・あいまい検索 | ショートカットを覚えていなくても、名前（日本語）で探せる。あいまい検索は件数が少ないうちは要らない |
| 選んだときの入れ方 | **`/…` の部分を本文で置き換える**。カーソルは本文の末尾 | 本文の後ろに改行を足す | 本文の末尾に改行を入れるかはテンプレートの書き手が決める（本文の最後を改行にしておけば、その次の行から書ける） |
| ショートカットの形 | **英小文字・数字・`-`・`_`、1〜32 文字、先頭は英小文字か数字**。重複は不可（409） | 日本語も許す | 日本語入力の `/` は全角の `／` になりやすく、`/翻訳` は打ちにくい。日本語は名前で探せる |
| 管理画面の入口 | **設定モーダルの「Prompt Templates」の「管理」ボタン**と、**候補の一番下の「テンプレートを管理」** | ヘッダーにボタンを足す | ヘッダーはもう混んでいる。候補から直接開ければ、使っている途中に足したくなったときに近い |
| 削除の確認 | **その行の中で 2 段階**（「削除」を押すと「削除する / やめる」に替わる） | 確認なし（会話の削除と同じ）・`window.confirm` | 元に戻す手段が無い。会話と違い、本文を書き直す手間がかかる。`confirm` はテーマに合わず E2E でも扱いにくい |
| 件数の上限 | **100 件**（超える作成は 400） | 上限なし | 一覧の取得・候補の描画をページ分けせずに済む。個人の利用で 100 件を超えることは考えにくい |

## データ

```prisma
// 入力欄の `/` で呼び出すプロンプトのテンプレート（#28）
model PromptTemplate {
  id        String   @id @default(uuid())
  name      String // 表示名（候補・管理画面）。最大 MAX_PROMPT_TEMPLATE_NAME_LENGTH 文字
  shortcut  String   @unique // `/` の後ろに打つ名前（先頭の `/` は含めない）
  content   String // 入力欄に入れる本文。最大 MAX_MESSAGE_LENGTH 文字
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
```

- 会話・メッセージとはリレーションを持たない（会話を消してもテンプレートは残る）。
- 上限値は `lib/shared/validation.ts` に足し、管理画面と API が同じ定数を使う（`error-handling.md`）。

| 定数 | 値 | 根拠 |
|---|---|---|
| `MAX_PROMPT_TEMPLATE_NAME_LENGTH` | 50 | 候補の 1 行に収まる長さ |
| `MAX_PROMPT_TEMPLATE_SHORTCUT_LENGTH` | 32 | 打って呼び出す名前として十分 |
| （本文） | `MAX_MESSAGE_LENGTH`（10,000） | 入力欄に入れる本文なので、送れる長さを超えさせない |
| `MAX_PROMPT_TEMPLATES` | 100 | 上の論点のとおり |
| `PROMPT_TEMPLATE_SHORTCUT_PATTERN` | `^[a-z0-9][a-z0-9_-]*$` | 上の論点のとおり（長さは別の定数で見る） |

- 名前・ショートカットは前後の空白を除いてから検証する。本文は空白だけを不可とし、前後の空白・改行は残す（末尾の改行に意味があるため）。
- ショートカットは保存の前に小文字にする（`/Translate` と `/translate` を別にしない）。

## API

| メソッド | パス | 用途 | 成功 | 失敗 |
|---|---|---|---|---|
| GET | `/api/prompt-templates` | 一覧（ショートカットの昇順） | 200 `{ templates: PromptTemplate[] }` | 500 |
| POST | `/api/prompt-templates` | 作成 | 201 作成したテンプレート | 400（形・長さ・ショートカットの形・件数の上限）・409（ショートカットの重複）・500 |
| PUT | `/api/prompt-templates/[id]` | 置き換え（名前・ショートカット・本文をすべて送る） | 200 置き換えたテンプレート | 400（ID の形・ボディ）・404・409・500 |
| DELETE | `/api/prompt-templates/[id]` | 削除 | 200 `{ success: true }` | 400（ID の形）・404・500 |
| POST | `/api/prompt-templates/examples` | 例の 4 件を作る（一覧が空のときだけ） | 201 `{ templates: PromptTemplate[] }` | 409（一覧が空でない）・500 |

- ボディの検証は `lib/server/request-body.ts` に `parsePromptTemplateBody` を足す（作成と置き換えで同じ形）。DB に触る前に検証する（`error-handling.md`）。
- 重複は、事前の確認ではなく一意制約の違反（Prisma の `P2002`）を 409 にする（確認と作成の間に同じ名前で作られても食い違わない）。
- 件数の上限は作成の前に数える（同時に 2 件作られて 101 件になることはありうるが、個人の利用では起きないので許す）。
- 置き換え・削除の 404 は、会話の更新・削除と同じく更新件数で判定する。
- 例の作成は、一覧が空かを確かめてから 3 件を 1 つのトランザクションで作る。押し間違えて二度押しても、2 回目は 409 で何も作らない。
- 409 はメッセージの保存（クライアント採番の `id` の重複）と同じく、一意制約の違反を `lib/server/prisma-error.ts` の `isUniqueConstraintError()` で判定する。形は他と同じ `{ error: string }`。

例の 4 件（`app/api/prompt-templates/examples/route.ts` の `EXAMPLE_TEMPLATES`）:

| ショートカット | 名前 | 本文 |
|---|---|---|
| `translate` | 英語に翻訳 | 以下を自然な英語に翻訳してください。\n\n |
| `review` | コードレビュー | 以下のコードをレビューし、不具合・可読性・性能・セキュリティの観点で改善点を重要なものから挙げてください。\n\n |
| `summarize` | 要約 | 以下を 3〜5 行で要約してください。\n\n |
| `slides` | スライドにまとめる | 以下の内容を発表用のスライドにまとめてください。1 枚目はタイトルのスライドにし、スライドの間は `---` だけの行で区切り、各スライドは `## 見出し` で始めて箇条書きを 3〜5 個にしてください。全体をコードブロックで囲まないでください。\n\n（#36。応答の「保存」→ スライドで 1 枚ずつ分けるため。`docs/26-html-slides-export.md`） |

## 入力欄での呼び出し

```
┌───────────────────────────────────────────┐
│ /translate   英語に翻訳                     │ ← 選択中（↑↓ で移る）
│ /review      コードレビュー                 │
│ ───────────────────────────────────────── │
│ ⚙ テンプレートを管理                         │
└───────────────────────────────────────────┘
┌───────────────────────────────────────────┐
│ /tr▌                                  [送信] │
└───────────────────────────────────────────┘
```

- 候補は入力欄の上に重ねて出す（入力欄を押し下げない）。
- **出す条件**: 入力欄の文字列が `/` で始まり、2 文字目以降に空白・改行が無い。`/` の後ろの文字列を絞り込みの語にする。
- **キー操作**（候補が出ている間だけ。IME の変換中は何もしない）:

  | キー | 動作 |
  |---|---|
  | ↑ / ↓ | 選択を移す（端で反対の端へ回る） |
  | Enter / Tab | 選択中のテンプレートを入れる（送信しない） |
  | Escape | 候補を閉じる（生成中でも停止しない。もう一度 Escape で停止） |
  | それ以外 | 入力を続け、絞り込みを更新する |

- 候補を押しても入れる。押した後は入力欄にフォーカスを戻す。
- 一致するものが無いときは「一致するテンプレートはありません」を出し、Enter はいつもどおり送信する（`/` で始まる文を送りたいとき、候補が邪魔をしない）。
- Escape で閉じた後は、入力を書き換えるまで出さない（閉じたのにすぐ開き直さないため）。
- 一覧が空のときは「テンプレートがありません」と「例を追加」を出す。このときも Enter は送信する（「例を追加」は押したときだけ）。
- テンプレートの一覧は画面を開いたときに 1 回読み、管理画面で変えたら読み直す。読めなかったときは候補を出さない（入力欄はいつもどおり使える）。
- 支援技術向けに、入力欄を `role="combobox"`（`aria-expanded`・`aria-controls`・`aria-activedescendant`）、候補を `role="listbox"` / `role="option"` にする。
- 入れた本文が `MAX_MESSAGE_LENGTH` を超えることは無い（本文の上限が同じため）。入れた後に書き足して超えたときは、今の超過の警告が出る。

## 管理画面

共通の `Modal` のダイアログ（`PromptTemplateDialog`）。

```
┌ プロンプトテンプレート ─────────────────────── ✕ ┐
│ [+ 新しいテンプレート]                            │
│ ┌──────────────────────────────────────────┐ │
│ │ /translate  英語に翻訳          [編集] [削除] │ │
│ │ 以下を自然な英語に翻訳してください。          │ │ ← 本文の先頭 1 行
│ └──────────────────────────────────────────┘ │
│ ┌ 編集中 ─────────────────────────────────┐ │
│ │ 名前        [コードレビュー           ]    │ │
│ │ ショートカット /[review              ]    │ │
│ │ 本文        [                        ]    │ │
│ │                          [やめる] [保存]   │ │
│ └──────────────────────────────────────────┘ │
└────────────────────────────────────────────────┘
```

- 一覧・作成・編集・削除を 1 つのダイアログで行う。編集はその行をフォームに替える（同時に開くフォームは 1 つ）。
- 保存・削除の失敗（409 の重複を含む）は、API の `error` をフォームの下に出し、入力を残す。
- 削除は行の中で 2 段階（「削除」→「削除する / やめる」）。
- 入力を失わないよう、背景のクリックでは閉じない（会話の役割のダイアログと同じ）。編集中に閉じようとしたときの確認は付けない（保存していない入力は捨てる）。
- 入口: 設定モーダルの「Prompt Templates」の「管理」ボタン（設定モーダルを閉じてから開く。ダイアログを重ねない）と、候補の一番下の「テンプレートを管理」。

## テスト

| 層 | 対象 |
|---|---|
| UT | 候補を出す条件（`/` だけ・空白・改行・先頭以外の `/`・全角の `／`）・絞り込み（前方一致が先・名前の部分一致・大文字小文字）・本文の入れ方・ボディの検証（長さ・形・小文字化・空白だけの本文・型違い・`null`） |
| IT | CRUD（一覧の順・作成・置き換え・削除）・重複の 409（作成・置き換え）・404・ID の形の 400・ボディの 400・件数の上限・例の作成（空のときだけ・2 回目は 409）・エラーの形 `{ error }` |
| E2E | `/` で候補が出て、↑↓・Enter・Tab・クリックで入れる・絞り込み・Escape で閉じる（生成は止めない）・一致しないときの Enter は送信・文の途中の `/` では出ない・例を追加・管理画面での作成・編集・削除（2 段階）・重複のエラー表示・一覧の API の失敗で候補を出さない（`page.route`）。Ollama を使わない（テンプレートを入れるところまで）ため、軽量モデル・CI でも動く |

## やらないこと

- テンプレートの変数（`{{input}}` に選択中の文字を入れる等）（#28 Phase C）
- カテゴリ・管理画面の検索（#28 Phase C）
- JSON のインポート / エクスポート（#28 Phase C）
- 送信時の展開（`/translate こんにちは` を送ると本文に替える）
- 文の途中・行頭の `/` での呼び出し
- テンプレートの並べ替え（ショートカットの昇順で固定）
- 会話の役割とテンプレートを一緒に選ぶ（役割は今のダイアログのまま）
