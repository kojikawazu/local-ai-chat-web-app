# qwen3-coder-next:latest

> 最終更新: 2026-10-17

**旧既定モデル**（#111 で `qwen3.8:27b` に切り替えるまで）。比較・共通の内容は [README](./README.md) を参照。

測定: 仕様・メモリは 2026-10-17（Ollama 0.40.5）、応答速度・ツール呼び出しは 2026-04-02 の検証（[09 エージェント機能 設計書](../09-agent-architecture.md) の技術検証結果）。いずれも 64GB の Apple Silicon Mac。

## 仕様

| 項目 | 値 |
|---|---|
| アーキテクチャ | qwen3next |
| パラメータ数 | 79.7B |
| 量子化 | Q4_K_M |
| 文脈長 | 262,144 |
| 必要な Ollama | 0.15.5 以上 |
| 対応機能 | completion / tools |
| ファイルサイズ | 51GB |
| ライセンス | Apache 2.0 |

## 実測値

| 項目 | 値 |
|---|---|
| 読み込み時のメモリ | 約 58GB（うち GPU 54GB） |
| エージェント | ツール判断 1〜2 秒・最終回答 1〜2 秒 |

## 挙動

- **思考過程**: 思考しない（thinking に非対応）
- **ツール呼び出し**: `done: false` のチャンクにまとめて届く。並列呼び出しは `index` で区別

## 評価

### 良い点

- コード生成に強い
- 思考しない分、応答が速い

### 注意点

- 読み込み時 約 58GB。文脈長 262K 分の KV キャッシュまで確保するため、ファイルサイズ（51GB）より大きくなる
- GPU に載ったモデルはスワップできず、64GB の Mac では他のアプリが使えるのは残り約 10GB になる。Docker Desktop と同時に動かすと空きメモリが 7% まで落ち、ブラウザの音声再生が止まった（#110）
- 使い終わったら `ollama stop qwen3-coder-next:latest` で解放する
